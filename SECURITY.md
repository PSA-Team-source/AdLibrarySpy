# Security

Please report vulnerabilities privately through GitHub's **Report a vulnerability** button
(Security tab) rather than a public issue. We reply within two business days.

In scope: the code in this repository, and the endpoints it calls
(`adlibraryspy.com/api/public/*`, `adlibraryspy.com/api/mcp`).

Never paste an `ADLIBRARYSPY_API_KEY` into an issue. If one leaks, revoke it at
https://adlibraryspy.com/settings/api.
